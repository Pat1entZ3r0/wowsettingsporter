How it works

  1. Snapshot a beta character once its addons and settings are the way you like them.
  2. On launch day, create your new character and log in once, then exit the game. That makes WoW create the character's folders.
  3. Apply the snapshot: type the new character's first and last name and pick the ruleset. The porter copies the addons and settings and rewrites every place the old name, ruleset and realm appear inside the addon data.
  4. Log in. If something looks off, restore the backup from Backups.

Everything stored on your PC is copied: addons and their settings, keybinds, macros, game options like auto loot and camera distance, chat windows and frame positions. Two things live only on Blizzard's servers and can't be copied as files: which spells sit on your action bars, and Edit Mode layouts. For Edit Mode, copy the layout string in game and save it with the snapshot: the Apply page then gives you a Copy button to paste it into the new character.
